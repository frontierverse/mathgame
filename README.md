# 수학 적립 금고 · mathgame

클로드에서 확인한 「수학 적립 금고 앱」 디자인을 반영한 모바일 친화형 웹 앱입니다. Next.js 16, React 19, TypeScript와 기존 Supabase DB를 사용합니다.

## 구현 범위

- 내 페이지의 실제 DB 학생 카드 선택 → 해당 학생의 화면으로 로그인 → 학생 바꾸기. `Youth`의 ID·이름·입소일·퇴소일을 서버에서 읽습니다. 기존 숨김 학생과 폐쇄·삭제 처리된 학생은 제외합니다.
- 하단 메뉴: 공부 / 보상받기 / 내 페이지. 화면에는 아이콘만 보이고 접근성 이름은 유지합니다.
- 공부 기본 화면: 월별 달력. 날짜를 누르면 해당 날짜의 개념학습이 열리고, 돌아오면 같은 월과 선택 날짜를 유지합니다. 월 이동과 오늘·완료·예정·미완료 표시를 제공합니다.
- 첫 개념: 개념 0 「분수와 음수」. 원본의 분수 조각과 수직선 그림을 사용해 분수 곱셈 / 양수 더하기 / 음수 더하기를 한 화면씩 보여줍니다. 숫자와 색상으로 관계를 연결하고, 순서는 직접 넘길 수 있습니다.
- 연습 6문제: 정답마다 별 1개, 오답은 다시 풀기, 필요할 때만 짧은 힌트, 완료 시 간식 쿠폰 1장
- 완료 화면의 한 줄 기록은 보상 이동 아래에 접힌 선택 항목입니다.
- 최종 테스트 3문제: 제출한 답은 바꿀 수 없고, 정답당 1,000원, 최대 3,000원의 적립 예시
- 내 페이지: 학생별 금고, 별·쿠폰·학습일, 이번 주 달력과 내역. 학생별 연습·테스트·기록은 서로 분리됩니다.
- 시연용 학습 날짜는 2026.9.29–10.16의 평일이며 개념 0으로 연결합니다. 다른 날짜에는 ‘등록된 개념 없음’을 표시합니다. 후속 개념 문제는 등록하지 않았습니다.

문제는 `src/app/curriculum.ts`, 학습 날짜와 진행도 타입은 `src/app/studentProgress.ts`에 등록되어 있습니다. 문제 선택지는 MathML로 표시합니다. 학생별 실제 입소·퇴소일과 한국 시간으로 남은 일수를 계산합니다. 날짜가 미등록이면 `—`를 표시합니다. 수·금 외의 날에는 테스트를 미리 체험할 수 있습니다.

학생 선택은 서버가 명단을 확인하고 발급하는 서명된 HttpOnly 세션으로 유지합니다. 카드 선택 방식이며 비밀번호를 통한 본인 확인은 없습니다. 세션은 7일 동안 유효하고 새로고침 후 복원됩니다. 다른 업무 앱의 관리자 권한이나 세션과 공유하지 않습니다.

별·학습일·쿠폰 수령 상태·최종 테스트 답·한 줄 기록은 `Youth.id`에 연결된 `MathLearningProgress`에 저장합니다. 새로고침·재접속·학생 전환 후 DB에서 다시 읽습니다. 서버가 답과 문제 순서를 검사하며 중복 적립과 제출한 답 변경을 거절합니다. 버전 조건을 사용해 동시 제출이 기록을 덮어쓰지 않도록 합니다. 새 학생은 실제 저장 기록이 없으면 0부터 시작합니다. DB 오류 시 오류와 다시 불러오기를 표시하며 임시 명단으로 대체하지 않습니다.

적립 예시는 저장된 테스트 정답으로 계산합니다. 실제 금전 지급·외부 쿠폰 발급은 연결하지 않았습니다.

## DB 설정

서버 환경 변수: `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, 32자 이상의 `AUTH_SECRET`. 마이그레이션에는 `DIRECT_URL` 또는 `DATABASE_URL`을 사용합니다. 인증키는 클라이언트로 전달하지 않습니다.

```sh
npm run db:migrate
```

`supabase/migrations/202610080001_create_math_learning_progress.sql`이 학습 테이블을 추가합니다. RLS를 적용하고 일반 Supabase 클라이언트의 직접 접근을 차단하며 서버의 service role만 조회·저장합니다. 기존 학생 테이블이 있는 DB를 대상으로 실행합니다.

## 로컬 실행

Node.js 20.9 이상을 사용합니다. 검증 환경은 Mac의 Node.js 22.21.0 / npm 11.6.2입니다.

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3000
```

이 Mac의 브라우저에서 http://127.0.0.1:3000 을 엽니다. 이 주소는 Mac의 localhost이며 다른 컴퓨터에서 직접 접속할 수 없습니다.

## 검증

```sh
npm run lint
npm test
npm run build
```

원본과 브라우저 화면의 비교, 반응형·문제·보상 검증은 `design-qa.md`에 기록했습니다.

실제 DB 연동을 점검하려면 `npm run test:db`를 실행합니다. 공개 명단에서 제외되는 검증용 학생을 만들고 저장·재조회·동시 제출을 검사한 뒤 검증용 학생과 학습 기록을 정리합니다. 실제 학생의 기록은 변경하지 않습니다.
